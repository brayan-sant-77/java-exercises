Imagine que você foi contratado para desenvolver uma pequena funcionalidade para uma loja. A empresa precisa consultar e filtrar seus produtos de acordo com os preços.

Sua tarefa é criar uma classe Product com os seguintes atributos:
- name — nome do produto.
- price — preço do produto.
  Crie uma lista contendo pelo menos oito produtos diferentes.

Utilize Streams para realizar as seguintes operações:

1. Produtos acima de R$ 50

Exiba somente os produtos cujo preço seja superior a R$ 50.

2. Produtos abaixo de R$ 30

Exiba somente os produtos cujo preço seja inferior a R$ 30.

3. Nomes dos produtos

Exiba somente os nomes de todos os produtos cadastrados.

4. Produtos entre R$ 30 e R$ 100

Exiba somente os produtos cujo preço esteja dentro desse intervalo, incluindo os limites.
Regras
- Utilize Streams em todas as operações.
- Cada operação deverá criar sua própria Stream.
- Não utilize for ou while.
- Não modifique a lista original.
- Utilize filter() e map() quando necessário.
- Organize seu projeto em pacotes domain e test.
