Objetivo
-  
Criar um sistema simples de caixa

O programa deve possuir um menu com as seguintes opções:

1 - Adicionar Dinheiro

2 - Sacar Dinheiro

3 - Consultar saldo

4 - Encerrar

Regras:
-
- O saldo começa em 0
- Não pode sacar mais do que possui
- não pode aceitar valores negativos
- usar métodos para cada operação

Conceitos:
- 
- if
- switch
- métodos
- Scanner
- validação
